# 成都 · CHENGDU CITY GUIDE

一个以「天府之国 · 熊猫故乡」为主题的中文城市介绍单页网站。页面采用杂志式排版、深色影像与米色纸感交替的视觉节奏，并包含横向地标画廊、风味选择器、行程切换、方言翻牌与「城市夜听」音乐播放器等交互。

## 文件结构

```
chengdu/
├── index.html              # 单页入口（与 cd1.mp4、音乐文件同目录）
├── cd1.mp4                 # 本地城市影像（05:34，1280×720）
├── 蔡琴明月几时有.mp3       # 本地背景音乐（蔡琴《明月几时有》）
├── css/
│   └── style.css           # 视觉系统、响应式布局、动效样式
├── js/
│   └── main.js             # 加载、滚动、画廊、视频、音乐、菜单等交互
├── assets/
│   ├── poster.jpg          # 首屏 / 城市印象海报（视频截帧）
│   └── still-city.jpg      # 城市影像栏目封面（视频截帧）
└── README.md
```

## 使用方式

直接双击 `index.html` 即可浏览。视频与音乐文件均与页面位于同一目录，通过相对路径读取。

如需通过本地服务器预览：

```bash
# 任选一种
python -m http.server 8000
npx serve .
```

然后访问 `http://localhost:8000`。

> 说明：视频与音乐都不会自动播放。点击首屏「观看城市影像」、页头「城市影像」或影像栏的大播放按钮后，会滚动至播放器并开始播放；点击页头「夜听」、生活区的「城市夜听」卡片或右下角迷你播放器可以播放 / 暂停背景音乐。视频播放时音乐会自动暂停，避免两个音轨重叠。

## 页面结构

1. 首屏影像 + 城市名片
2. 滚动字幕带
3. 城市印象（数字统计、城市坐标、引语）
4. 城市影像（本地视频 `cd1.mp4`）
5. 城市地标（8 个横向画廊卡片）
6. 人间风味（6 道川味 + 动态味觉视觉）
7. 成都生活（成都十二时辰 + 城市夜听音乐卡片）
8. 行程灵感（一日 / 两日 / 三日路线切换）
9. 实用指南（抵达、出行、时节、贴士）
10. 成都话翻牌 + 结尾 + 页脚

## 交互与适配

- 响应式断点：1280 / 1100 / 900 / 640 / 380 px
- 桌面端：自定义光标、首屏视差、磁性按钮、卡片 3D 倾斜、地标画廊拖拽与键盘方向键浏览
- 移动端：全屏菜单、触摸横向滑动、视频播放器、紧凑型音乐控制条
- 音乐：页头快捷控制、内嵌黑胶唱片卡片、可关闭的迷你播放器、进度拖动、时间显示
- 无障碍：跳转链接、ARIA 标签、键盘可操作标签页 / 画廊 / 翻牌 / 播放器，支持 `prefers-reduced-motion`
- 无外部字体、图片或脚本依赖，离线可用
